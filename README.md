# TTT Helper: rider view

Follow your DS's team time trial live on your own phone or computer. You watch the same screen and clock
as the DS, with the same changeover calls. The DS runs the race; you cannot change anything.

## Open the rider page

**https://yfhg26.github.io/Team_Time_Trial/**

Works in Safari (iPhone), Chrome (Android, PC, Mac) and Edge. Nothing to download, install or sign up to.

## Join a session

1. Open the link above.
2. Type the **session code** your DS gives you (it looks like `k3m9-xq7a-w2ht`) and tap **Join**.
3. You should see "Following the DS · live", with the race clock and who is pulling.
4. Tap the **speaker icon** (top right) to turn sound on. It starts off. Tap once for beeps and
   announcements, again for beeps only, again for off.
5. To leave, tap the strip at the top ("Following the DS") and choose **Leave session**.

## Before the race

- **Date and time:** set your phone or computer to set the time automatically. If the clock is out, your
  timer can be out.
- **Sound on iPhone:** turn the side switch off silent, turn the volume up, and tap the speaker icon after
  you have joined. Turn off Low Power Mode if you can, as it can pause web pages.
- **Keep the screen awake:** the page asks to keep the screen on. If your phone still locks, set
  Auto-Lock to a longer time or "Never" for the race.
- **Internet:** you need a connection the whole time. It uses very little data.
- **Test it:** join your DS's test session a few minutes early and check you hear a beep.

## If something is wrong

| What you see | What to do |
|---|---|
| "That is not a session code" | Check the code with your DS. Letters and numbers only, with dashes. |
| "Waiting for the DS" | The DS has not started sharing yet. It will appear by itself. |
| "Lost contact with the DS. Still trying." | Check your internet. It reconnects by itself. If it stays, leave and join again with the same code. |
| "The DS ended the session." | The race is over, or the DS stopped sharing. Ask for a new code if they restart. |
| No sound | Tap the speaker icon until it says "Beeps + announcements". Check volume and the silent switch. Tap the screen once and wait for the next call. |
| Page looks old after an update | Reload it, or add `?v=2` to the end of the address. |

## For the DS

Riders only follow. The DS runs the full TTT Helper (the builder file), builds the plan, starts a live
session and shares the code. Keep the DS app open and the screen awake during the race.
